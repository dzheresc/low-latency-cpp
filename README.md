# low-latency-cpp

A Claude skill for designing, writing, reviewing and tuning latency-sensitive C++
(trading, telecom, market data, real-time control): threading, atomics, queues,
memory, CPU/OS tuning, networking and tail latency.

Distilled from Leandro Silveira's six-part Medium series
"Low-Latency C++ Systems Engineering".

## Layout

```
skills/low-latency-cpp/SKILL.md
```

## Install

- **Claude Code:** copy `skills/low-latency-cpp/` into `~/.claude/skills/` (personal)
  or `.claude/skills/` in a project.
- **claude.ai:** zip the `low-latency-cpp` folder and upload it under Settings → Capabilities → Skills.
